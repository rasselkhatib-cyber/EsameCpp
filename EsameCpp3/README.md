# EsameCpp - Gestione Caserma

How to build and run:

1. Build using the Makefile:

```
make
```

2. Run the program:

```
./caserma
```

3. Clean build artifacts:

```
make clean
```

You can also use the provided build script:

```
./build.sh
```

If you have any compilation errors, run the exact failing command and paste the full output here so I can inspect it. If the program crashes or behaves incorrectly, describe or paste the console sequence leading to the issue.
